# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales data using Python, Pandas, and Matplotlib.
It helps identify the best-selling products, highest-revenue regions,
and revenue distribution across product categories.

## Technologies Used
- Python
- Pandas
- Matplotlib

## Project Features
- Calculates total sales revenue.
- Analyzes revenue by product.
- Compares revenue across regions.
- Analyzes revenue by category.
- Displays charts for data visualization.

## Dataset
The dataset contains the following columns:
- Date
- Product
- Category
- Region
- Quantity
- Price

## Key Findings
- Total Revenue: ₹508,900
- Highest-Revenue Product: Laptop — ₹250,000
- Highest-Revenue Region: South — ₹212,000
- Highest-Revenue Category: Electronics — ₹398,900

## How to Run the Project

1. Install Python.
2. Install the required libraries:

   pip install pandas matplotlib

3. Keep `analysis.py` and `sales_data.csv` in the same folder.
4. Run the following command:

   python analysis.py

## Purpose
This project was created to practice Python programming,
data analysis, and data visualization.
